# α-side — app downloads

The builds of the α-side app, the social network for music lovers.

**How to install:** see **[www.alpha-side.com/download](https://www.alpha-side.com/download)**.

- **Android:** download `alpha-side.apk` from the [latest release](https://github.com/T1C0x/alpha-side-releases/releases/latest) and install it.
- **iPhone:** download `alpha-side.ipa` and install it with [SideStore](https://docs.sidestore.io/docs/installation/prerequisites).

This repository only holds the release files. Questions or problems: use “Contact support” in the app’s settings.
